Ground and Camera Boundaries - Architecture Diagram
====================================================

Note: Boundary positions shown below are example values.
Actual boundaries are dynamically set per scenario:
- scenario.gd defaults: ±50 units
- scenario_1.tscn: ±60 units
- Camera defaults (before scenario load): ±200 units

Camera Constraint Algorithm:
=============================

1. User Input → Camera Movement
                    │
                    ▼
2. Update Orbit Center (where camera looks at ground)
                    │
                    ▼
3. Check Boundaries
   ┌────────────────┴────────────────┐
   │                                  │
   ▼                                  ▼
   Within Bounds?                 Outside Bounds?
   │                                  │
   │                                  ▼
   ▼                              Clamp to Boundary
   No Change                          │
                                      ▼
                              Adjust Camera Position
                              (maintain same offset)


Coordinate Reference:
=====================

World Center: (0, 0, 0)
Ground Level: Y = 0
Flat Ground:  Y = -2
Boundaries:   Defined per scenario (default ±50, scenario_1 uses ±60)

Camera Orbit Center Constraints:
  X: scenario.boundary_min_x to scenario.boundary_max_x
  Z: scenario.boundary_min_z to scenario.boundary_max_z
  Y: 0 (calculated from ground intersection)

Fade Zone: 50 units from boundary
  Starts fading at: boundary ± 50
  Fully visible at: boundary ± 0
